Current screen purpose:
This screen is the finance command center for one case. It combines:
- financial summary
- operational next-step guidance
- case finance profile editing
- reusable case contact memory
- payment logging and payment history
- invoice creation/editing/deleting
- sending invoice emails and reminder emails
- viewing email history
- finance activity timeline
- shared automation/email defaults

Current top-level logic shown to the user:
- The page header shows the case title, case ID, request type, last updated timestamp, current finance status, and a refresh action.
- The top summary area shows:
  - Contract amount
  - Total paid
  - Outstanding amount
  - Total invoiced
- It also shows quick operational context:
  - Client summary
  - Service summary
  - Reminder/email summary
- It shows a “Recommended next move” card based on business rules.
- It shows extra signal cards such as:
  - overdue invoice state
  - whether reusable client email exists
  - whether email automation/sender is configured
- It offers quick actions:
  - add payment
  - create new invoice
  - compose email

Recommended-next-move logic:
The current recommendation is computed like this:
- If there are overdue invoices: recommend following up / sending reminder, and point user to Communication
- If there is remaining balance and no invoices: recommend creating the first invoice, and point user to Invoices
- If there is remaining balance and no payments: recommend capturing payment progress, and point user to Payments
- If no reusable client email exists: recommend storing a reusable contact email, and point user to Overview
- If contract value exists and remaining balance is zero or less: recommend review/settled state, and point user to Activity
- Otherwise: recommend general review / keeping the record current

Business intent behind the page:

- Shared automation defaults may be too heavy/noisy inside the case page
- The page could better separate “case-level data”, “money workflow”, and “system/admin settings”
